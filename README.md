# 🏋️‍♂️ Health & Fitness Challenge Platform — Frontend (Angular & AI Integration)

An advanced, interactive web application built with Angular 19, featuring full-stack challenge management and an integrated AI Agent to assist users with personalized fitness insights, dynamic interaction, and smart recommendations.

🔗 **Backend Repository:** [https://github.com/titirot/fitness-challenges-backend.git](https://github.com/titirot/fitness-challenges-backend.git)

---

## 🛠️ Tech Stack & Architecture

- **Frontend Framework:** Angular 19 (TypeScript, SCSS, RxJS)
- **AI Integration:** Custom AI Assistant / Agent integration via REST APIs & Function Calling for dynamic interactive guidance
- **Security & State:** JWT (JSON Web Tokens) Authentication, Angular Interceptors & Reactive Forms
- **UI & Experience:** Fully responsive modern dashboard and interactive components

---

## ✨ Key Features

- **🧠 Smart AI Assistant:** Embedded AI agent interface providing real-time fitness guidance, automated recommendations, and interactive capabilities directly within the platform.
- **🔐 Secure Authentication:** Robust sign-up and login workflow secured with JWT tokens and route guards.
- **🏆 Challenge Management:** Discover, join, and track active health and fitness challenges seamlessly.
- **📊 Interactive Progress Tracking:** Visual metrics and progress logs to keep participants motivated.
